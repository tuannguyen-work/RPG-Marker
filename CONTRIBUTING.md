# Contributing

## Licensing of contributions

By submitting a contribution you agree that it is licensed under the
**GNU GPL version 3 or (at your option) any later version**, together with the
additional permission in `APP_STORE_EXCEPTION.md`. Add your name to `AUTHORS`
in your first pull request.

Every commit must be signed off (Developer Certificate of Origin,
https://developercertificate.org):

    git commit -s

Do not submit code you do not have the right to license this way, and do not
copy code from projects with incompatible licenses (see
`THIRD_PARTY_NOTICES.md`).

## Source file header

New source files start with:

    //  SPDX-License-Identifier: GPL-3.0-or-later
    //  Copyright (C) <year> The RPG-Marker Authors. See AUTHORS.

## Content policy

This project is a player only. Do not add games, RPG Maker RTP assets,
features for downloading games from the internet, or tools that decrypt or
extract assets from games.
